# 네이버 블로그 초안 (blog.naver.com/misun7255)

사이트(manbokrae.com)의 질문 페이지와 짝을 이루는 블로그 글 초안이다. 사이트에 배포되지 않는다.

- 표기는 항상 `만복래숯불구이`, 지역은 `봉계`로 통일한다.
- 글 끝에 사이트 링크는 하나만 건다. 링크 도배는 하지 않는다.
- 사진은 직접 찍은 매장·음식 사진을 쓴다.
- 사실이 바뀌면 사이트·플레이스·블로그를 함께 고친다.
